# SYSTEM

All exhibits are based on a modular system. We have developed a range of connection solutions for 3D printing. The system is also compatible with the ITEM D30 system and can be expanded.

Here you can find information and materials about the construction system used throughout the exhibition.

![SYSTEM](999_system/04%20media/You%20Decide_Sample%20Wall%20System%20Connectors%20.jpg)

## Grid

The grid system is based on a modular design with a 157 mm grid and a 9 mm margin. The system panels are milled from 19 mm pine and feature Ø30 mm grid holes. They are compatible with the item D30 system for expansion.

![Grid](999_system/04%20media/You%20Decide_Grid%20System.jpg)
