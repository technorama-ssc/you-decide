# Die Münze

- Die Spielmünze bleibt nie bis zum Ende der Woche
- Sobald die Spielmünze weg ist, legen die Gäste eigene, echte Münzen in die Schatulle
- Diese Münzen entfernen wir jeweils. Es werden jedoch andauernd wieder neue hineingelegt
- Einige Gäste verstecken sogar Münzen unter dem Polster im Etui
